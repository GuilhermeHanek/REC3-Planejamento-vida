# Planejamento de Vida - Guilherme

Projeto simples com contadores regressivos para os objetivos pessoais de Guilherme.

## Metas

| Objetivo | Prazo |
|----------|-------|
| 🚗 CNH | 1 ano |
| 💰 Estabilidade Financeira | 6 anos |
| 🏠 Casa Própria | 10 anos |

## Como funciona

O site mostra um timer que conta dias, horas, minutos e segundos até cada meta ser alcançada.
